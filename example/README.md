# super_auto_suggestion_box example

Runnable gallery for `super_auto_suggestion_box` 0.14.0 with `super_core` 3.3.0.
It demonstrates local, remote-fallback, paged, fuzzy, multi-select, recents,
inline-create, validation, read-only, and advanced-search scenarios in light,
dark, LTR, and RTL modes. It also includes a fixable-field example demonstrating
`allowFixed`, controller-owned focus wiring, and `formFieldKey` validation.
Field labels, supporting text, placeholders, and prefix icons use the standard
`InputDecoration` API.

```bash
flutter pub get
flutter run
```
