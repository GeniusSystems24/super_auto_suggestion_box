# super_auto_suggestion_box example

Runnable gallery for `super_auto_suggestion_box` 0.13.0 with `super_core` 3.3.0.
It demonstrates local, remote-fallback, paged, fuzzy, multi-select, recents,
inline-create, validation, read-only, and advanced-search scenarios in light,
dark, LTR, and RTL modes.

```bash
flutter pub get
flutter run
```
